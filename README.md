# Day 21 – OWASP Top 10:2025 | Risk Identification

**Assignment:** Day 21  
**Topic:** OWASP Top 10:2025 – Risk Identification  
**Total Marks:** 20  
**Domain:** Cybersecurity | Web Application Security

## 📌 Project Overview

This assignment focuses on understanding the OWASP Top 10:2025 security risks in web applications. It covers security fundamentals, vulnerability identification, risk analysis, and defensive security recommendations.

## 🎯 Learning Objectives

- Understand OWASP and its Top 10 security risks.
- Learn vulnerabilities, threats, assets, and security risks.
- Understand Authentication vs Authorization.
- Identify and classify OWASP Top 10:2025 categories.
- Analyze fictional security scenarios.
- Identify and protect important student portal assets.

## 📚 Topics Covered

- OWASP Security Fundamentals
- OWASP Top 10:2025 Categories
- Authentication and Authorization
- Security Risk Identification
- Scenario-Based Risk Analysis
- Asset Identification and Protection
- Defensive Security Recommendations

## 🔍 Practical Analysis

Analyzed five fictional security scenarios:

1. Broken Access Control
2. Security Misconfiguration
3. Software Supply Chain Failures
4. Insecure Design
5. Security Logging and Alerting Failures

## 🛡️ Key Learning Outcomes

- Identified common web application security risks.
- Understood the importance of access control and secure configuration.
- Learned how software supply chain failures affect application security.
- Developed basic risk identification and defensive analysis skills.
- Understood the importance of protecting sensitive assets.

## ⚠️ Safety Notice

This assignment is strictly for educational purposes and fictional scenario analysis.

- No real websites were tested.
- No vulnerability scanning was performed.
- No exploitation or attack techniques were used.
- All analysis was conducted using the provided fictional scenarios.
